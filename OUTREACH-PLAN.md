# KRONOS MCP — Plan de captación inicial

## Objetivo
Conseguir conversaciones técnicas y validar un caso de uso piloto
sin gastar en publicidad.

## Semana 1
1. Revisar documentación de instalación y configuración.
2. Preparar una demostración reproducible y sin secretos.
3. Identificar tres problemas concretos de integración MCP.
4. Participar de forma útil en una discusión técnica relevante.
5. Ajustar la oferta piloto según el feedback.
6. Registrar el interés real y decidir el siguiente paso.

## Canales iniciales
- GitHub: repositorio y discusiones técnicas oficiales de MCP.
- Discord: comunidad de desarrolladores MCP, respetando sus reglas.
- GitHub Agents Working Group: colaboración técnica pertinente.

## Criterios de validación
- Un problema concreto descrito por un posible usuario.
- Confirmación de que el alcance actual puede resolverlo.
- Aceptación explícita de una prueba piloto.
- Alcance, plazo y precio acordados antes del desarrollo.

## Límites
No publicar automáticamente.
No enviar mensajes masivos.
No prometer capacidades no implementadas.
No exponer credenciales ni datos privados.
