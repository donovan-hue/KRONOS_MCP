Building KRONOS MCP: permission-controlled tools over MCP

KRONOS MCP is a TypeScript-based Model Context Protocol server that
connects compatible clients to an existing KRONOS API through stdio.

The current implementation provides four read-only tools, runtime
permission checks for protected tools, structured error handling,
and automated tests.

The local test suite currently passes 65 tests. Live verification is
a separate check. This is an initial integration foundation, not a
complete AI platform.

I'm interested in hearing from developers and small software teams
working with APIs, MCP servers, or permission-controlled integrations.

What API or workflow would you want to connect to an MCP-compatible
assistant, and what security requirements would that integration need?

Project: https://github.com/donovan-hue/KRONOS_MCP
