# KRONOS MCP — Oferta piloto

## Objetivo
Evaluar si KRONOS MCP puede conectar un cliente compatible con MCP
con una API existente de forma útil y controlada.

## Alcance inicial
- Una API y un caso de uso definidos.
- Revisión de compatibilidad y autenticación.
- Prueba de concepto limitada a operaciones de lectura.
- Validación de permisos y tratamiento de errores.
- Informe de resultados, limitaciones y próximos pasos.

## Fuera del alcance
- Generación de contenido con IA.
- Escritura, publicación o eliminación de datos.
- Integraciones arbitrarias no evaluadas.
- Certificación o garantía absoluta de seguridad.
- Servicios de pago o infraestructura no acordados.

## Condiciones comerciales
El alcance, los entregables, el plazo y el precio se acordarán
antes de comenzar el desarrollo. La viabilidad técnica debe
confirmarse antes de prometer una integración.

## Resultado esperado
Una prueba de concepto reproducible que permita decidir si
conviene ampliar la integración.

## Requisitos del interesado
Describir la API, el cliente MCP, el problema operativo y los
requisitos de seguridad. No enviar contraseñas ni tokens por
mensajes públicos.

## Protección de datos
Utilizar credenciales de prueba cuando sea posible y no solicitar
acceso a datos reales innecesarios.
